# Projeto da cadeira de Programação Estruturada: Jogo da Velha Inteligente

Nome dos integrantes: Caio Paiva, Thiago Lacerda

Descrição: O projeto é desenvolver um jogo da velha inteligente, no qual é impossível ganhar, apenas empatar ou perder, usando métodos específicos para isso. O objetivo também é fazer esse jogo rodar de forma multiplayer em máquinas diferentes utilizando socket.
